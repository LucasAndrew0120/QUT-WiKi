# 交通出行

> 本篇将介绍学校内外的交通方式，帮助你更好地在校园内和校外出行。


## 黄岛校区

### 校内交通

| 交通工具             | 费用   | 备注                                  |
|------------------|------|-------------------------------------|
| 步行、私有自行车        | /    | 黄岛校区由于地形没有共享自行车                     |
| 私有电动车            | /    | 自2025级起，学校不再登记新的私有电动车进校园            |
| 共享电动车(小程序沃易行)    | 起步1元 | 1km&20min以下收费1元，暂时停车最多30min         |
| 摆渡车(小程序享坐车)      | 2元/人 | 从校内多个站点和南2门之间往返                     |
| 地铁站摆渡公交(小程序e定真情) | 2元/人 | 从校内多个站点和薛家岛地铁站之间往返，出校允许交通卡二维码，入校不允许 |
| 市北校区摆渡大巴         |  免费   |                                |

### 校外交通

| 交通工具 | 费用                   | 备注                                                                 |
|------|----------------------|--------------------------------------------------------------------|
| 地铁   | 依照“递远递减”的原则，采用里程分段计价 | [青岛地铁票务规则](https://www.qd-metro.com/news/view.php?id=1387#pagetop) |
| 公交   |                      | **未查询到官方文件**                                                       |
| 网约车  |                      | 从黄岛校区南门和薛家岛地铁站之间单向10元左右                                            |

> 及其不建议乘坐出租车，当地出租车收费乱象极其严重，建议出行选择网约车

## 交通卡

- 在国家“交通联合”政策推广下，全国已经有超过300个城市的公交、地铁等交通工具可以使用同一张交通卡。
- “琴岛通”是青岛市发行的交通卡，对青岛市的公交，地铁有优惠政策，同学们可以通过下载“青岛地铁”APP；手机开启NFC，绑定“琴岛通”交通卡；或者进入微信，支付宝交通卡小程序等等。
- 文末我会附上“交通联合”城市列表，方便同学们查询。

## 中国铁路学生票规定

> 来源：[《铁路旅客运输规程》](https://mobile.12306.cn/otsmobile/h5/otsbussiness/info/transportationRules.html)（2026年6月1日起施行）第十六条
> 
> 新生入学后，学校会统计个人信息并上传学籍到学信网，同学们可前往**12306 APP**校验学生资格

### 适用对象

在以下院校就读的学生、研究生，**家庭居住地与学校所在地不在同一城市**时可购票：

- 全日制高等学校（含民办）
- 承担研究生教育任务的科研机构
- 军事院校
- 普通中、小学和中等职业学校
- 国家宗教事务局批准的正式宗教院校

### 购票凭证

| 学生类型 | 凭证 |
|---------|------|
| 大学生/研究生 | 附火车票学生优惠卡的学生证（优惠区间加盖院校公章） |
| 中、小学生 | 加盖学校公章的书面证明 |

### 优惠次数

- 每学年（10月1日～次年9月30日）：**4次单程**（家庭居住地 ↔ 院校/实习地点）
- 新生凭录取通知书：当年开学前可购 **1次**（家庭→学校）
- 毕业生凭学校证明：当年可购 **1次**（学校出发）
- 华侨及港澳台学生：可购学校所在地至口岸城市间的学生优惠票

### 适用席别

- 普通旅客列车：硬座、硬卧
- 动车组列车：二等座、二等包座、多功能座、一等座、动车组卧铺

### 资质核验

- 每学年乘车前须通过 **12306网站** 或 **车站窗口/自动售票机** 办理 **1次** 核验
- 需携带：有效身份证件 + 学生证（附优惠卡）
- 优惠卡缺失、信息不全、无法识别或与学生证不一致的，**无法通过核验**

### 未核验的处理

1. 列车先**补收票价差额**，开具客运记录
2. 到站后 **30日内** 凭车补车票、学生证、身份证件到窗口办理
3. 核实通过后：扣减优惠卡次数 → **退还车补票款，不收退票费**

### 其他

- 联程车票开车5天以内扣减1次优惠次数
- 超过优惠区间不发售学生票
- 优惠次数**按学年有效**，不可结转至下学年
